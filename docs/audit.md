# 项目审计记录
## 验证通过项
1. **前端文章增删改查全闭环**：前端实现了“写文章”和“删除文章”的 UI 交互，发布新文章成功保存到数据库，删除文章后列表也能正常联动刷新。
2. **数据持久化稳定性**：按 Ctrl+C 停掉后端再重启，去 Swagger 执行 GET /api/articles，数据完全还在；前端刷新数据正常显示。
3. **响应式布局与错误兜底**：浏览器窗口缩窄到手机尺寸时，导航栏文字自动隐藏并折叠为汉堡菜单（☰），点击可展开收起。
4. 统一错误返回格式与输入校验：我在 Swagger 里发送了带有空日期 "date": "" 的非法 JSON，后端自动拦截并返回了统一的 {"code": 422, "message": "请求参数校验失败", "data": [...]}，证明了 Pydantic 校验和全局错误拦截均生效。
## 已知 遗留瑕疵（暂未处理）
- 1.开发后期由于频繁重启，本地积累了多个僵尸终端，导致前端出现 `Failed to fetch`
- **最终修复**：彻底清理全部终端进程，重新干净地启动后端（`uvicorn main:app --reload`）和前端（`npm run dev`），后端终端成功输出 `GET /api/articles 200 OK`。
- **结论**：前后端联调完美打通，数据持久化稳定。前端在网络冲突时优雅显示了“文章暂时无法加载”的容错提示，而非白屏。
-2. 由于最后阶段进行过“全量代码重写”，早期实现的“重置数据”按钮在重写过程中被遗漏，目前无法在 UI 上直接重置 localStorage。
